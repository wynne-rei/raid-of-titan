# RAID OF TITAN v4 実装TODO (2026-04-14)

## コアコンセプト
ティアキン風空島マップ × Tribes of Midgard風昼夜サイクル × 巨大TITANが襲う。
プレイヤーは中央本拠地のクリスタルを守り、空島を渡り歩いて廃墟修復・宝箱回収・番人撃破で強化する。

---

## Phase 1: マップ大改修（空島化）
- [ ] 現行の平地マップを撤去
- [ ] 中央大空島（本拠地：城＋クリスタル配置）を生成
- [ ] 周辺に6つの小〜中サイズ空島を配置
- [ ] 空島の高さ・サイズをバラけさせる（ティアキン感）
- [ ] 空島下は奈落（落下演出 → 中央大空島にリスポーン）
- [ ] 島間に壊れた橋を配置（初期は渡れない）

## Phase 2: ドラゴン→タイタン全置換
- [ ] `DRAGON_DEFS` 削除、`TITAN_DEFS` に統一
- [ ] 名前付きタイタン7体データ定義
  - GRUNT / WARRIOR / STONEBREAKER / ASHKING / FROSTJAW / VOIDWALKER / TITAN LORD
- [ ] 各タイタンの固有HP・攻撃パターン・色・サイズ定義
- [ ] Minecraft風ボクセルメッシュ差分

## Phase 3: 昼夜サイクル
- [ ] `BUILD` → `DAY`（探索・修復フェーズ）にリネーム＆機能拡張
- [ ] `WAVE` → `NIGHT`（襲撃フェーズ）にリネーム
- [ ] 「就寝」ボタンで昼を終わらせる
- [ ] 環境光・スカイボックスを昼夜で切り替え
- [ ] 日数カウンター（Day 1, Day 2...）をHUDに

## Phase 4: 番人タイタン（空島間徘徊）
- [ ] 各空島に番人タイタンを割り当て（6体）
- [ ] 番人は「島と島の間」を徘徊（複数島にまたがる）
- [ ] 巨大スケールで顔や手が複数島に乗ってる見た目
- [ ] プレイヤーが攻撃 or 近づくと敵対化
- [ ] 倒すと島が解放（視覚変化：光る/浄化演出）
- [ ] **3分後に復活**

## Phase 5: 夜の襲撃タイタン
- [ ] 夜になると外周から名前付きタイタン1体がスポーン
- [ ] クリスタル目指して進軍
- [ ] 1夜1体、ウェーブごとに違う名前
- [ ] 撃退で翌朝へ、クリスタル破壊で敗北
- [ ] 名前表示（「FROSTJAW 襲来！」など）

## Phase 6: 巨人崩壊演出
- [ ] HP%で段階変化（100% / 75% / 50% / 25%）
- [ ] 各段階で見た目劣化：パーツ欠け、発光ダウン、煙/ヒビ
- [ ] 挙動変化：移動速度ダウン、攻撃間隔増

## Phase 7: 廃墟修復（リソース消費なし）
- [ ] 修復対象は「橋」と「城＋大砲」の2種のみ
- [ ] 橋修復：隣島へ渡れる（物理的に繋がる）
- [ ] 城＋大砲修復：前線基地化、大砲が自動で敵を撃つ
- [ ] 近づくとUI表示「[E] 修復」
- [ ] ボタンで即修復（リソース消費なし）

## Phase 8: カード配置（クラロワ風）
- [ ] 既存のカード設置を継承
- [ ] 設置場所制限なし（空島上ならどこでも）
- [ ] 武装は自動戦闘

## Phase 9: 既存システムの整理
- [ ] 城壁セグメント → 中央大空島のみ残す
- [ ] ウェーブ間インターバル → 昼フェーズに吸収
- [ ] ミニマップ → 空島対応（島ごとのアイコン）

```
Phase 1 (マップ) → Phase 2 (タイタン化) → Phase 7 (橋修復＝移動解放)
  → Phase 3 (昼夜) → Phase 4 (番人) → Phase 5 (夜襲撃)
    → Phase 6 (崩壊演出) → Phase 8 (カード) → Phase 9 (整理)
```

## 検証
1. 中央大空島で起動、周辺に6島が見える
2. 橋を修復すると隣島に渡れる
3. 番人タイタンが島間にまたがって立ってる
4. 番人を倒すと3分後復活
5. 夜になると名前付きタイタンが襲来
6. タイタンHP減ると見た目崩壊
7. クリスタル破壊で敗北、翌朝で日数カウント進む
